# Web-Basics-HTML-Beginner-All-Classes
A comprehensive collection of 23 HTML modules covering web development fundamentals and semantic tags.

### 📚 What's inside this repository:
- **Foundations:** Headings, Paragraphs, and Text Formatting.
- **Media:** Working with Images, Audio, and Video tags.
- **Structures:** Lists, Tables, and Layouts using Blocks.
- **Forms:** Deep dive into Form tags and attributes (From A to Z).
- **Advanced:** Iframes, Quotations, and Semantic HTML.
